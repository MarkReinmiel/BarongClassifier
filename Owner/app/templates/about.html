BARONG TAGALOG

About

BarongClassifier helps identify selected Barong Tagalog textiles through image-based classification while preserving Philippine heritage through technology.

Dataset Information

The dataset contains images related to selected Barong Tagalog textile materials.

The textile categories included in the system are Piña, Jusi, Cocoon, and Others.

Model Information

BarongClassifier uses image-based classification to identify textile materials from uploaded images.

Model: MobileNetV2

Input Size: 224 × 224 pixels

Number of Classes: 3

Training Epochs: Up to 20 epochs
